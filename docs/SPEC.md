# Darask Paint — 仕様書 (v1)

## 0. 背景と最重要要件

Krita の起動が遅いことへの不満が出発点。**「超高速起動・軽量・シンプル」** なラスタ画像編集ソフトを作る。
迷ったら常に「起動速度・軽さ・シンプルさ」を優先して判断すること。

数値目標(リリースビルド、通常のデスクトップPC):

| 項目 | 目標 |
|---|---|
| 起動時間(プロセス起動 → 最初のフレーム描画) | **300ms 以内** |
| 配布物 | **単一 exe、15MB 以下**(ランタイム・インストーラ不要) |
| アイドル時 CPU 使用率 | **ほぼ 0%**(入力がない限り再描画しない) |
| 描画追従 | 4000×4000px 画像でブラシが 60fps で追従 |

## 1. 技術スタック

- Rust stable (x86_64-pc-windows-msvc)、edition 2021
- GUI: **eframe / egui**(glow レンダラ、デフォルト機能で可)
- 画像 I/O: **image** crate(`--no-default-features -F png,jpeg,bmp,gif,webp`)
- ファイルダイアログ: **rfd**
- クリップボード: **arboard**
- 依存はこの4つのみ。**安易に crate を追加しない**(コンパイル時間・バイナリサイズ・起動時間に直結)。

`main.rs` 先頭に `#![windows_subsystem = "windows"]`(コンソール窓を出さない)。

リリースプロファイル:

```toml
[profile.release]
opt-level = 3
lto = "thin"
codegen-units = 1
strip = "symbols"
panic = "abort"
```

## 2. 非目標

筆圧 / 芸術的フィルタ(ぼかし・シャープ等。基本的な色調補正は v4 §24 で解除)/ 印刷 / **in-process・汎用プラグイン機構**(外部コンパニオンプロセス連携のみ v12 §55 で限定解除)/ UI 多言語切替(**UI は日本語固定**)/ フェザー(ぼかし)付き選択 / 磁性なげなわ / ブラシのカスタム形状。
これらを「ついで」に実装しないこと。
(段階的に解除してきた旧非目標: レイヤー=v2 §13、テキスト=v3 §19、非矩形選択・グラデーション・色調補正・設定の永続化=v4 §21〜§26、レイヤー/履歴付き保存形式=§36、レイヤーのブレンドモード=v12 §50、外部プラグイン連携=v12 §55〜§56)

- キャンバス外の作業領域は暗灰色。

## 4. ツール(左縦ツールバー)

各ボタンはベクターアイコンを上、短い日本語名を下に置く一体タイル+ツールチップ(完全名とショートカット)。左パネルは約84pxで、低いウィンドウでは縦スクロールできる。

| ツール | キー | 挙動 |
|---|---|---|
| ペン | B | 丸筆・ハードエッジ(デフォルト)。オプションでアンチエイリアス ON/OFF。左ドラッグ=プライマリ色、**右ドラッグ=セカンダリ色**。ポインタイベント間は線分補間して途切れない線にする |
| 消しゴム | E | 丸筆ハードエッジで **透明(alpha=0)** にする |
| 直線 | L | ドラッグでプレビュー、離して確定。Shift で 45° 単位に拘束。太さ=ブラシサイズ、端は丸 |
| 矩形 | R | ドラッグでプレビュー→確定。モード: 枠線のみ / 塗りつぶし / 両方(枠=プライマリ、中=セカンダリ)。Shift で正方形 |
| 楕円 | C | 矩形と同様。Shift で正円 |
| 塗りつぶし | F | スキャンラインflood fill。許容値スライダー 0–255(デフォルト 0)。連結領域のみ |
| スポイト | I | 左クリック=プライマリに、右クリック=セカンダリに取得。**描画系ツール使用中も Alt+クリックで一時スポイト** |
| 選択 | M | §6 参照 |
| 手のひら | H | ドラッグでパン。**どのツール中でも Space 押下中ドラッグ・中ボタンドラッグでパン可** |

- ブラシサイズ: 1–64px、オプションバーのスライダー、`[` / `]` で減増。
- 単一キーのツールショートカットは、テキスト入力中(`ctx.wants_keyboard_input()`)は無効にすること。

## 5. 色

- オプションバーに プライマリ/セカンダリ の2スウォッチ(重ね表示)。クリックで egui 標準のカラーピッカーがポップアップ(`color_edit_button_srgba`)。
- `X` で入れ替え。
- 最近使った色 8 個を横並び表示(クリックでプライマリに)。描画確定時に使用色を先頭に追加(重複は先頭へ移動)。
- 色は RGBA(アルファ含む)。

## 6. 選択(フローティング方式)

- ドラッグで矩形選択(破線表示)。
- 選択内部をドラッグ → その領域を**浮動化**(元位置は透明で埋める)して移動。以後のドラッグは浮動片の移動。
- `Delete`: 選択領域(または浮動片)を消去(透明化)。
- `Ctrl+C` / `Ctrl+X`: コピー / 切り取り(切り取りは透明で埋める)。
- `Ctrl+V`: クリップボード画像をビュー中央に浮動片として貼り付け。**ただしドキュメントが完全に未編集・未保存(起動直後の白紙)の場合は、ドキュメント自体を貼り付け画像のサイズに置き換える**(スクリーンショット→保存が最短になるように)。
- 確定: `Enter`、選択外クリック、ツール切替 → 浮動片をその位置に合成し 1 回の undo 単位にする。`Esc` = その場で確定して選択解除。
- `Ctrl+A`: 全選択。
- 浮動片はキャンバス外にはみ出してよい(確定時にクリップ)。

## 7. メニュー

- **ファイル**: 新規 (Ctrl+N) / 開く (Ctrl+O) / 上書き保存 (Ctrl+S) / 名前を付けて保存 (Ctrl+Shift+S) / 終了 (Alt+F4)
- **編集**: 元に戻す (Ctrl+Z) / やり直し (Ctrl+Y, Ctrl+Shift+Z) / 切り取り / コピー / 貼り付け / 削除 / すべて選択 / 選択解除 (Ctrl+D)
- **画像**: 画像サイズ変更… / キャンバスサイズ変更… / 選択範囲でトリミング / 左右反転 / 上下反転 / 右に90°回転 / 左に90°回転
- **表示**: 拡大 (Ctrl++) / 縮小 (Ctrl+-) / 100% (Ctrl+1) / ウィンドウに合わせる (Ctrl+0)

ダイアログ仕様:
- **新規**: 幅・高さ(1–8192、デフォルト 1280×720)、背景 = 白 / 透明。
- **画像サイズ変更**: 幅・高さ(縦横比固定チェック、デフォルトON)、補間 = バイリニア / ニアレスト。
- **キャンバスサイズ変更**: 幅・高さ。既存画像は左上基準で配置、拡張部分は透明。
- ダイアログは egui のモーダル(`egui::Modal` が使えるバージョンならそれを使用)。

## 8. ファイル I/O・クリップボード

- 読み込み: `.dpaint` / PNG / JPEG / BMP / GIF(先頭フレーム)/ WebP。画像形式の内部表現は常に RGBA8。
- 保存: 新規ドキュメントの既定は、レイヤーと全 undo/redo を保持する `.dpaint`。PNG / JPEG / BMP は可視レイヤーを統合した画像書き出しとして維持する。拡張子で判定し、不明な拡張子は従来互換で `.png` に補正する。
- JPEG 保存時は品質ダイアログ(1–100、デフォルト 90)。アルファは白に合成してから保存。
- ドラッグ&ドロップ: **画像**(PNG/JPEG/BMP/GIF/WebP)はアクティブタブへ**新規レイヤーとして追加**(キャンバス中央に配置。キャンバスは広げない。はみ出した画素は見えないがレイヤーに残し、あとからキャンバスを広げると現れる。1 undo 単位、レイヤー上限時はトースト)。**`.dpaint` は新規タブで開く**(§30 と同じ重複検出)。**フォルダはページ集**(§54)。対応外の拡張子はトースト。
- 未保存変更ガード: 閉じる / 新規 / 開く の前に「保存しますか?」モーダル(保存 / 破棄 / キャンセル)。ウィンドウの閉じる要求は `close_requested` を検知して `ViewportCommand::CancelClose` で止めてから確認。
- I/O エラーで**絶対にパニックしない**。ステータスバーにトースト(約4秒表示)でエラー内容を出す。

## 9. アンドゥ / リドゥ

- `Ctrl+Z` / `Ctrl+Y`。
- undo/redo はデフォルトで全件保持し、`.dpaint` 保存時は現在カーソルを含め全件を永続化する。設定の件数は履歴パネルの表示件数であり、履歴の論理削除上限ではない。
- 1 ストローク・1 図形・1 塗りつぶし・1 貼り付け確定 = 1 undo 単位。
- サイズ変更・回転・トリミング等は全画像スナップショットの undo 単位。

## 10. ズーム / パン

- `Ctrl+ホイール`: カーソル位置を中心にズーム(段階 ×1.25)。範囲 5%–3200%。
- ホイール: 縦パン、`Shift+ホイール`: 横パン。
- 100% 以上はニアレスト補間(ピクセルがくっきり見える)、100% 未満はリニア。
- 100% 表示は物理ピクセル 1:1(DPI スケールに負けない)。
- パンは画像が完全に画面外へ消えないようクランプ(最低 32px は見える)。

## 11. 起動ベンチマークモード(必須機能)

環境変数 `DARASK_BENCH=1` で起動した場合:
- `main()` 冒頭で `Instant::now()` を記録。
- 2 フレーム目の `update()` 終了時に、経過ミリ秒をカレントディレクトリの `bench.txt` に書き出して `std::process::exit(0)`。
- これが起動時間目標(300ms)の検証手段であり、GUI を対話せずにスモークテストする手段でもある。

## 12. 品質基準

- `cargo build` は **エラー 0・警告 0**。`cargo fmt` 適用済み。
- `unwrap()` / `expect()` を I/O・ユーザー入力経路で使わない(プログラミング上の不変条件のみ可)。
- 純粋ロジック(ラスタ演算、座標変換、履歴、flood fill)にはユニットテスト必須。`cargo test` 常時グリーン。
- UI 文字列はすべて日本語。フォントは Windows システムフォント(游ゴシック等)を実行時ロード(ARCHITECTURE.md 参照)。

# v2 拡張仕様

v1 の全要件(起動 300ms・単一 exe 15MB・アイドル CPU 0%・警告 0 等)は v2 でも維持する。

## 13. レイヤー(最小実装)

- ドキュメントは 1 枚以上のレイヤーを持つ(下から上に合成、通常合成のみ、ブレンドモードなし)。上限 64 枚。
- 各レイヤー: 名前 / 表示・非表示 / 不透明度 0–100%。
- 描画系ツール(ペン・消しゴム・図形・塗りつぶし)、選択・浮動片、クリップボード操作は**アクティブレイヤーのみ**に作用する。
- スポイトは**合成結果**から色を取る。塗りつぶしの連結判定はアクティブレイヤーのピクセルで行う。
- 消しゴムはアクティブレイヤーを透明化(全レイヤー透明の部分は市松模様が見える)。
- 画像メニューの操作(サイズ変更/キャンバスサイズ/トリミング/反転/回転)は**全レイヤー**に適用。
- 新規作成・ファイルを開いた直後は「背景」レイヤー 1 枚。新規レイヤーは透明で名前は「レイヤー N」。
- PNG/JPEG/BMP への画像書き出しは常に**統合(可視レイヤーの合成)**する(PNG は合成アルファ保持、JPEG/BMP は白に合成)。複数レイヤーを画像形式へ保存した場合は「レイヤーは統合して保存されました」と通知する。`.dpaint` はレイヤー構成と履歴を保持し、統合トーストを出さない(§36)。
- 右パネルのレイヤーセクション:
  - 一覧(最上位レイヤーが一番上に表示)。行 = 表示チェック + 名前。クリックでアクティブ化(ハイライト)、ダブルクリックで名前変更。
  - ボタン: 新規 / 複製 / 削除 / 上へ / 下へ / 下と結合。レイヤーが 1 枚のときは削除・結合は無効。
  - アクティブレイヤーの不透明度スライダー。
- メニュー「レイヤー」: 新規レイヤー (Ctrl+Shift+N) / レイヤーを複製 / レイヤーを削除 / 上へ移動 / 下へ移動 / 下のレイヤーと結合 (Ctrl+E) / 画像の統合 (Ctrl+Shift+E)。
- アンドゥ: 描画パッチはレイヤー番号付き。レイヤーの追加/複製/削除/移動/結合/統合も 1 undo 単位。**表示切替と不透明度変更は履歴に積まない**(仕様として明記)。
- レイヤー操作・アンドゥは浮動片やストローク進行中にはツール切替と同じ扱い(先に確定してから実行)。

## 14. カラーパネル(色相リング + SV 三角形 + パレット)

右パネル上段。egui 標準ポップアップピッカーは廃止し、以下を常時表示する:

1. **スウォッチ**: プライマリ/セカンダリの重ね表示 + 入替ボタン(X キーと同じ)。編集対象は常にプライマリ。
2. **色相リング + SV 三角形**(直径約 170px):
   - 外周リング(ドーナツ)で色相を選択。0°=赤を 12 時方向、時計回り。リング上に現在色相のマーカー。
   - 内接する**固定向きの正三角形**(頂点: 上=純色相 S=1,V=1 / 左下=黒 V=0 / 右下=白 S=0,V=1)で彩度・明度を選択。三角形内に現在 S/V のマーカー。
   - リング内ドラッグ=色相のみ、三角形内ドラッグ=S/V のみ変更(ドラッグ開始領域で確定し、外れてもクランプ)。
3. **アルファスライダー**(0–255、市松模様の下地付き)と **HEX 入力欄**(#RRGGBB / #RRGGBBAA、確定で反映)。
4. **パレット**: 定義済み 24 色(2 段 × 12。1 段目: 黒 #000000, 灰 #7F7F7F, 白 #FFFFFF, 赤 #E53935, 橙 #FB8C00, 黄 #FDD835, 緑 #43A047, 水 #00ACC1, 青 #1E88E5, 紫 #8E24AA, 桃 #EC407A, 茶 #6D4C41。2 段目は各色の明るいパステル調)。クリック=プライマリ、右クリック=セカンダリ。
   - 「＋」でプライマリ色をユーザーパレットに追加、ユーザー色は右クリックメニューで削除。永続化はしない(§2)。
5. **最近使った色 8 個**(v1 のものをオプションバーからここへ移動)。

## 15. ツールアイコン

- 左ツールバーは **egui Painter によるベクター描画アイコン**(約 18×18、線幅 ~1.5pt)の直下に短い日本語ラベルを常時表示する。アイコンと文字は同じクリック領域。画像アセット・絵文字フォントは使わない(サイズ・起動時間・DPI・テーマ追従のため)。
- 9 ツール: ペン=鉛筆 / 消しゴム=傾いた角丸矩形 / 直線=斜め線 / 矩形=矩形枠 / 楕円=楕円枠 / 塗りつぶし=バケツ+滴 / スポイト=斜めのスポイト / 選択=破線矩形 / 手のひら=手(または十字矢印)。
- 色は egui のテキスト色(選択中はアクセント色)に追従。ツールチップ(日本語名+ショートカット)は維持。
- 一目で区別でき、20×20 で潰れないこと。

## 16. 選択・浮動片のスケールハンドル(※ Esc の挙動は v3 §18 で「キャンセル」に変更)

- 選択矩形および浮動片の外周に **8 個のハンドル**(四隅+各辺中央、約 7pt 角)を表示。
- ハンドルをドラッグすると拡縮(四隅=両軸、辺=単軸)。**Shift で縦横比固定**。アンカーは反対側の隅/辺。
- 未浮動の選択でハンドルを掴んだ場合は、内部ドラッグと同様にまず浮動化してから拡縮する。
- 拡縮は**浮動化時の元ピクセルから毎回バイリニアで再サンプリング**する(累積劣化させない)。最小 1px、最大 8192px。
- ハンドルホバー時はリサイズカーソルを表示。移動・確定・Esc 等の挙動(§6)は不変。
- 従来どおりメニューにも 画像サイズ変更 / キャンバスサイズ変更 / 選択範囲でトリミング がある(こちらは全レイヤー対象)。

## 17. ブラシエンジン(硬さ・不透明度)

ブラシ(旧ペン)・消しゴムを共通のストロークエンジンに刷新する:

- **硬さ** 0–100%(デフォルト 100)。半径 r に対し r×硬さ までカバレッジ 1、そこから外周 r までなめらかに減衰(smoothstep)。Shift+[ / Shift+] で ±10。
- **不透明度** 1–100%(デフォルト 100)。**Photoshop の opacity 意味論**: 1 ストローク内で何度重ねてもそのストロークの被覆は不透明度上限を超えない(カバレッジは max 合成)。ストロークをまたげば重なる。
- **鉛筆モード**(チェックボックス、デフォルト OFF): アンチエイリアスなしの2値スタンプ(ピクセルアート用)。硬さ無視、不透明度は有効。旧「アンチエイリアス」チェックは廃止(ブラシは常時 AA)。
- 消しゴムも同エンジン(不透明度=**強さ**として表示。カバレッジ×強さぶんアルファを減らす)。
- **Shift+クリック**: 直前のストローク終点から Shift+クリック地点まで直線をブラシで引く(PS 準拠)。
- **数字キー 1–9, 0**: ブラシ系ツールの不透明度を 10%〜90%, 100% に設定(テキスト入力中は無効)。
- **ブラシカーソル**: キャンバス上ではブラシ半径の円アウトライン(白+黒の二重線で背景を問わず視認可)を表示し、OS カーソルは非表示。画面上の円が 3px 未満になる場合は十字カーソルにフォールバック。

## 18. 移動ツール・ズームツール・自由変形・Esc の挙動変更

- **移動ツール (V)**: ドラッグで**アクティブレイヤー全体**を移動。選択範囲があればその範囲だけを移動(選択ツールの内部ドラッグと同じ浮動化)。実装はどちらも「自動浮動化→移動→確定」で統一(§16 のハンドルも表示され、そのまま拡縮可能)。
- **ズームツール (Z)**: クリック=クリック位置を中心に 1 段階拡大、Alt+クリック=縮小。カーソルは虫眼鏡。
- **Ctrl+T(自由変形)**: 選択範囲があれば浮動化してハンドル表示。なければ全選択→アクティブレイヤーを浮動化してハンドル表示。以降は §16 と同じ操作。
- **Esc の挙動変更(v1 §6 を上書き)**: Esc は**キャンセル** — 浮動片を破棄して元の位置・内容に完全復元し(切り出し元も戻す)、選択を解除する。履歴には何も積まない。確定は従来どおり Enter / 選択外クリック / ツール切替。テキスト編集中の Esc も入力破棄。

## 19. テキストツール (T)

- クリック位置にインラインのテキスト入力ボックス(egui TextEdit、複数行、IME 対応)を表示。入力中は全ツール系ショートカット無効。
- オプションバー: フォントサイズ 8–144px(デフォルト 24)。色はプライマリ。フォントは UI と同じシステム日本語フォント 1 種のみ(太字・斜体・フォント選択は非目標)。
- 確定(Ctrl+Enter または ボックス外クリック)でアンチエイリアス付きラスタライズし、**浮動片として配置**(移動・ハンドル拡縮可、Enter 等で通常確定=1 undo 単位)。Esc は入力破棄。
- 空文字列の確定は何もしない。クリック位置=テキストボックスの左上。行送りはフォントメトリクス準拠(約 1.3×サイズ)。
- 実装のため **ab_glyph を第 5 の依存として許可**する(`=0.2.32` に `=` 固定。当初は「egui が既に内部使用している」想定だったが、egui/epaint 0.35 は内部で ab_glyph を使っておらず(skrifa/harfrust 系に移行済み、`cargo tree -i ab_glyph` で確認可能)、darask-paint 単独の追加依存になっている。そのため「egui と同じバージョンに揃える」という制約自体は成立しないが、再現性のためのバージョン固定(`=`)は引き続き必須。ab_glyph 単体の追加コスト(`ab_glyph_rasterizer`/`owned_ttf_parser`/`ttf-parser` を含め計4クレート)はコンパイル時間・バイナリサイズへの影響が「実質ゼロ」というほどではないが小さい)。

# v4 拡張仕様(選択の一般化・グラデーション・色調補正・永続化・性能・CI/CD)

v1〜v3 の全要件(単一 exe 15MB・アイドル CPU 0%・警告 0 等)は v4 でも維持する。起動時間の目標は §28 で更新する。

## 21. マスク選択(選択機能の一般化)

矩形限定だった選択を**ビットマスク選択**に一般化する。v4 の全選択ツール・全編集操作の土台。

- 選択 = `bbox + バイナリマスク`(画素単位の 選択/非選択。フェザーは非目標)。
- 選択枠の表示は**マスク境界線**(選択画素と非選択画素の境界)を実線+破線で描く(アニメーションなし、従来どおり)。
- 浮動化・移動・スケールハンドル・コピー/切り取り/貼り付け/Delete・Ctrl+T は**マスク形状のまま**動作する(浮動片は非矩形になれる。スケール時はピクセルとマスクを同時に再サンプル)。
- **描画のクリップ**: 選択がある間、ブラシ/消しゴム/鉛筆/図形/塗りつぶし/グラデーション/色調補正は**選択範囲内にのみ**効く(カバレッジ×選択マスクで自然に合成)。塗りつぶしの連結探索も選択内に制限。
- 「選択範囲でトリミング」は bbox でトリミング。
- 既存の矩形選択は「マスクが全 1 の矩形」として同一コードパスに載せ替える(挙動不変)。

## 22. 選択ツールの拡充

| ツール | キー | 挙動 |
|---|---|---|
| 矩形選択 / 楕円選択 | M / **Shift+M で巡回** | 従来の矩形に加え楕円マスク。Shift ドラッグで正方形/正円 |
| なげなわ | **L**(**Shift+L** で自由↔多角形) | 自由: ドラッグの軌跡を閉じてマスク化。多角形: クリックで頂点追加、ダブルクリック/Enter/始点クリックで閉じる、Esc で中止 |
| 自動選択 | **W** | クリック画素から許容値(0–255、オプションバー)の連結領域をマスク選択(flood fill と同じ判定、アクティブレイヤー基準) |

- いずれも確定済み選択がある状態での新規選択は**置き換え**(加算/減算モードは非目標。ただし実装を将来拡張できる構造にする)。

## 23. グラデーションツール

- キー: **G**(**Shift+G** で 塗りつぶし↔グラデーション巡回)。
- ドラッグで始点→終点。ドラッグ中はプレビュー線+ライブプレビュー、離して確定(1 undo 単位)。
- 種類: **線形 / 円形**(オプションバー)。色: **プライマリ→セカンダリ / プライマリ→透明**(オプションバー)。
- 始点前/終点後はクランプ(端色で埋める)。選択範囲があればその中だけ。アクティブレイヤー対象。AA/ディザは無し(将来課題)。

## 24. 色調補正(画像メニュー > 色調補正)

すべて**アクティブレイヤー**対象、**選択範囲があればその中だけ**、各適用が 1 undo 単位。

- **明るさ・コントラスト…** — 各 −100〜+100 のスライダー、**ライブプレビュー付き**モーダル(OK/キャンセル。キャンセルで完全復元)。
- **色相・彩度・明度… (Ctrl+U)** — 色相 −180〜+180、彩度/明度 −100〜+100。同上のモーダル。
- **階調の反転 (Ctrl+I)** — 即時(RGB反転、アルファ不変)。
- **グレースケール化 (Ctrl+Shift+U)** — 即時(Rec.709 輝度)。
- ライブプレビューは不透明度スライダーと同じ「値が変わったフレームだけ再適用」方式。モーダル中の再適用は元画素スナップショットから毎回計算(累積適用しない)。

## 25. ブラシスムージング・ピクセルグリッド

- **スムージング(手ブレ補正)**: ブラシ/消しゴム/鉛筆のオプションに 0–100%。入力座標の指数移動平均(0=補正なし)。ストローク終端で最終点まで追いつかせる。Shift+クリック直線連結には適用しない。
- **ピクセルグリッド**: 表示メニューにトグル。ズーム 800% 以上のとき画像ピクセル境界に薄いグリッド線を描く(デフォルト ON)。

## 26. 設定の永続化・最近使ったファイル・バージョン情報

軽量な独自形式(`キー\t値` の UTF-8 テキスト、外部 crate 禁止・手書きパーサ+テスト)で `%APPDATA%\darask-paint\settings.txt` に保存する。**読み込みは起動時 1 回、書き込みは終了時と最近使ったファイル更新時のみ。破損・欠損時は黙って既定値**(起動を絶対に妨げない。§28 の起動目標に算入)。

永続化する項目(これ以外は追加しない): ウィンドウ寸法・最大化状態 / 最近使ったファイル(最大 8)/ ブラシ設定(サイズ・硬さ・不透明度・鉛筆・スムージング)/ ツールオプション(許容値・図形モード・グラデーション設定)/ プライマリ・セカンダリ色 / ユーザーパレット / 最後に使ったツール / ピクセルグリッド表示。

- **ファイル > 最近使ったファイル** サブメニュー(存在しないパスは選択時に一覧から除去してトースト)。
- **ヘルプ > バージョン情報**: バージョン(`CARGO_PKG_VERSION`)・リポジトリ URL を表示する小モーダル(メニューバーに「ヘルプ」追加)。

## 28. パフォーマンス目標(v4 で強化)

計測してから最適化する(推測での最適化禁止)。リリースビルドでの受け入れ基準:

| 項目 | 目標 |
|---|---|
| 起動(→初フレーム) | **中央値 160ms 以下**を目指し、300ms 以内は必須。`DARASK_BENCH=1` の bench.txt にフェーズ内訳(設定読込/フォント/ウィンドウ作成/初フレーム)を出力する |
| ブラシ追従 | 4000×4000・ブラシ64px の高速ドラッグでフレーム 16ms 以下(ドラッグを横断する巨大 dirty 矩形を作らない — セグメント単位の dirty 処理) |
| 履歴メモリ | ストロークの Patch を**タイル単位のサブパッチ集合**にし、離れた 2 点を触っても bbox 合併で面積爆発しない |
| 浮動片ハンドル | ドラッグ中の再サンプルはフレームあたり最大 1 回 |
| Esc キャンセル | 全レイヤー浮動化のキャンセル復元をタイル一括コピーで 50ms 以下(4000×4000) |
| ホットループ | composite / blend / flood fill を行スライス処理にし、画素単位の境界チェック呼び出しを排除 |

- `DARASK_DEBUG=1` のときのみ、フレーム時間のデバッグオーバーレイを表示してよい(通常起動には一切のコストを載せない)。

## 29. CI/CD・リリース

- **CI**(`.github/workflows/ci.yml`、windows-latest、main への push と PR):
  `cargo fmt --check` → `cargo clippy --all-targets -- -D warnings` → `cargo build --release` → `cargo test --release`。Rust キャッシュ利用。
  ベンチ(GUI 起動)はランナーがヘッドレスの可能性があるため `continue-on-error: true` の別ジョブ。
- **リリース**(`.github/workflows/release.yml`、`v*` タグ push 時):
  リリースビルド → exe を `darask-paint-v{X.Y.Z}-windows-x64.zip` に固めて GitHub Release を自動作成(自動生成ノート付き)。
- **clippy 警告 0** を新たな品質基準に追加する(既存コードの全 lint を解消してから CI を入れる)。
- **exe アイコン**: `assets/icon.ico`(自前生成でよい。生成スクリプトは `examples/gen_icon.rs`、image crate の ico 機能で出力)+ `build.rs` + build-dependency **winresource**(build-dependency はランタイム依存ではないため許可。これ以外の build-dependency は追加しない)。
- バージョンを **0.4.0** に上げる。以後、リリースはタグ push で行う。

# v5 拡張仕様(複数ドキュメント・タブ)

v1〜v4 の全要件(起動 300ms・単一 exe 15MB・アイドル CPU 0%・警告 0・clippy 0 等)は v5 でも維持する。

**読み替え規則**: v1〜v4 で「ドキュメント」「doc」「画像」と書かれている箇所は、v5 以降は**アクティブタブのドキュメント**を指す。ツール・色・ブラシ設定・パレット・最近使ったファイル・ウィンドウ状態は引き続きアプリ全体で共有(タブごとには持たない)。選択・浮動片・アンドゥ履歴・ズーム/パン・ファイルパス・未保存フラグは**タブごと**に独立する。

## 30. タブ(複数ドキュメント)

- メニューバーの直下、ツールバー/オプションバーの上に**タブバー**を新設(横1列、水平スクロール、多数タブでも折り返さない)。
- 各タブ: ファイル名(無題なら「無題」「無題2」「無題3」…と連番)+ 未保存インジケータ(`*`)+ 閉じるボタン(×)。クリックでアクティブ化、**中クリックでも閉じる**。
- **常に 1 タブ以上を維持する**: 最後の 1 タブを閉じようとした場合、そのタブを閉じるのではなく「新規」と同じ扱い(未保存ガードを通してから内容を白紙に戻す)にする。タブが 0 枚になる状態は作らない。
- タブ数の上限は **24**。超えて新規タブを作ろうとしたら作成せずトースト通知(SPEC §13 のレイヤー上限と同じ流儀)。
- **Ctrl+N(新規)** / **Ctrl+O(開く)** は、従来の「アクティブタブの内容を置き換える」から「**新規タブを追加してそこに開く**」に変更する(v1 §7・§8 を上書き)。開こうとしたファイルが既に開いているタブがあれば(パスを正規化して比較)、新規タブを作らずそのタブへ切り替える。最近使ったファイルからのオープンも同じ規則に従う。ドラッグ&ドロップの画像は§8のとおり新規レイヤー追加(`.dpaint` とフォルダだけがタブ/ページ集側)。
- **Ctrl+W**: アクティブタブを閉じる(未保存なら確認ダイアログ)。**Ctrl+Tab** / **Ctrl+Shift+Tab**: 次のタブ / 前のタブへ切り替え(端では反対側へ循環)。
- ウィンドウの閉じる操作(×ボタン・Alt+F4・Ctrl+Q 相当)は、未保存のタブがあれば**タブごとに順番に**確認ダイアログを出す(いずれかでキャンセルすれば閉じる処理全体を中止)。
- ウィンドウタイトルは引き続き `{アクティブタブのファイル名}{*} - Darask Paint` を表示する。
- タブの並べ替え(ドラッグでの順序変更)は非目標(v5 では実装しない、シンプルさ優先)。
- セッション復元(前回開いていたタブ一覧の記憶)は非目標。起動時は常にタブ 1 枚(コマンドライン引数があればそれを開いた状態、無ければ白紙の新規)。

## 31. 選択範囲を新規タブに複製

- 画像メニューに「**選択範囲を新規タブに複製**」を追加(「選択範囲でトリミング」の直後)。**選択または浮動片がアクティブなときのみ有効**(無ければグレーアウト、他の選択依存メニュー項目と同じ扱い)。
- 挙動:
  - **浮動片がある場合**: その浮動片のピクセル(mask込み)をそのまま新規タブの唯一のレイヤーにする。
  - **静的な選択のみの場合**: 選択マスクの bbox で、**全レイヤー**をマスク外transparentで切り出し、レイヤー構成(名前・表示・不透明度・重ね順・アクティブレイヤー)を保ったまま新規タブに複製する(「選択範囲でトリミング」の全レイヤー方針を踏襲)。
- 元のタブは一切変更しない(非破壊)。新規タブは元タブの**直後**に挿入されアクティブになる。新規タブの未保存フラグは **true**(ファイルに存在しない新しい内容のため)、パスは無し(「無題」系の命名)、アンドゥ履歴は空から始まる。

## 32. v5 キーマップ追加(§20 に追記)

| キー | 動作 |
|---|---|
| Ctrl+W | タブを閉じる |
| Ctrl+Tab | 次のタブ |
| Ctrl+Shift+Tab | 前のタブ |

## 33. メニューバーの全展開アイコン化

- 従来の「ファイル/編集/画像/レイヤー/表示/ヘルプ」ドロップダウン式メニューを廃止し、**全項目を常時表示のアイコン+短い日本語ラベルの縦タイル**として横一列(ウィンドウ幅が足りない場合は次の行へ折り返す)に並べる。カテゴリごとに薄い区切り線を入れるが、折り返しの行頭・行末では孤立した区切り線を省略する。

- 対象は以下の全項目(§7 ファイル/編集/画像/レイヤー/表示、§13 レイヤー、§19 テキスト由来の自由変形、§26 バージョン情報、v4/v5 の追加項目すべてを含む):
  **ファイル**: 新規 / 開く / 上書き保存 / 名前を付けて保存 / **最近使ったファイル**(可変長リストのため唯一の例外として、アイコンクリックで小さなポップアップリストを開く形にしてよい)/ タブを閉じる / 終了。
  **編集**: 元に戻す / やり直し / 切り取り / コピー / 貼り付け / 削除 / すべて選択 / 選択解除 / 自由変形。

## 34. 設定(環境設定)ダイアログ

- **Ctrl+K**(Photoshop 準拠)、または新設のアイコンボタンで開くモーダルダイアログ。
- 最小構成として **「履歴パネルの表示件数」**(1–500、デフォルト **50**)の数値入力を持つ。OK で全タブの表示上限へ反映+設定ファイルへ保存、キャンセルで破棄する。値を下げても undo/redo エントリは削除しない。
- この値は SPEC §26 の永続化対象に追加する(`%APPDATA%\darask-paint\settings.txt`)。

## 35. アンドゥ履歴パネル

- 右パネルに「色」「レイヤー」に続く 3 番目のセクション「**履歴**」を追加(アクティブタブの履歴を表示。タブ切替で表示内容も切り替わる)。
- 一覧はスクロール可能なリストで、現在位置の前後から設定件数までを時系列表示する。古い行を省略した場合は「(古い履歴もプロジェクトに保存されます)」と示す。初期状態が表示範囲内なら仮想的な「(初期状態)」行を表示する。
- **現在位置をハイライト**する。現在位置より後ろ(やり直し可能な範囲)の行は淡色表示にする。
- **行をクリックすると、その時点まで一気に戻る/進む**(複数手順のジャンプ)。ジャンプ後に新しい操作を行うと、淡色表示だった「やり直し」範囲は通常どおり破棄される(SPEC §9 の「新規 push で redo クリア」と同じ挙動)。
- ジャンプは既存の「元に戻す/やり直し」と同じ安全規則に従う: 進行中のストローク・浮動片があれば**先に確定してからジャンプする**(SPEC §13 最終項と同じ扱い。ジャンプだけを特別扱いしない)。
- 表示範囲外の履歴もメモリ上に保持し、`.dpaint` へ全件保存する。
- 「元に戻す/やり直し」のツールバーアイコン(§33)は従来どおり**単発ステップ**の操作のまま(複数ステップのジャンプは履歴パネルのクリックでのみ行う)。

## 36. Darask Paint プロジェクト形式 (`.dpaint` v1)

- 現在の全レイヤー(名前・表示・不透明度・順序・アクティブ位置)と、保存時点のカーソルを含む undo/redo 全件を保存し、読み込み後も両方向へ操作できる。
- 8-byte magic / version / endian / header長を持つ。各データは4-byte種別+64-bit長+CRC32のchunkで、未知chunkはCRC検証後に読み飛ばす。
- 画素は最大256×256のRGBA8タイルに分け、64-bit content hashで候補を引き、衝突時はbytes比較してから共有する。現在状態と全履歴を横断して重複排除する。
- リビジョンは親revision・操作種別・単調増加sequence・操作ラベル・checkpoint印を持つ線形グラフとして記録する。既存の軽量な `HistoryOp` 差分を保存し、redo側は内部スタック順も復元する。
- 外部入力はファイル/chunk/文字列/タイル/リビジョン/寸法/レイヤー数/復元メモリ総量に上限を設け、全長計算をchecked演算にする。件数と残りbyte数を割当前に照合し、fallibleなメモリ確保を使う。CRCに加え、全リビジョンを状態機械で検証し、各操作のレイヤー添字・寸法・カーソル時点のDOCS構造が矛盾するファイルも拒否する。writerにもloaderと同じ復元予算を適用し、保存成功した自作ファイルがこの上限差だけを理由に再読込不能にならないようにする。
- 保存は同一ディレクトリに一意なtmpを作成し、`write_all`→`flush`→`sync_all` 後、標準ライブラリの単一renameで新規作成または既存ファイルを置換する。失敗時は旧ファイルを維持してtmpを清掃し、最終出力にもファイル上限を適用する。
- PNG/JPEG/BMPは編集履歴を持たないflatten画像書き出しであり、`.dpaint`とは意味を分けてUI/ダイアログに示す。

# v8 拡張仕様(選択範囲を反転・結合部分をコピー)

v1〜v7 の全要件(起動 300ms・単一 exe 15MB・アイドル CPU 0%・警告 0・clippy 0)は v8 でも維持する。どちらも Photoshop 準拠の定番操作で、既存のマスク選択基盤(§21)とレイヤー合成(§13)の上の小さな追加。新しい依存・データ構造は作らない。

## 37. 選択範囲を反転

- 編集グループに「**選択範囲を反転**」(**Ctrl+Shift+I**、PS 準拠)を追加する(§33 の編集グループ「選択解除」の直後に追記)。
- 現在の選択マスクの**補集合**(ドキュメント範囲内の非選択画素)を新しい選択にする。結果の bbox は非ゼロ画素を含む最小矩形へ詰める(「選択範囲でトリミング」等の bbox 依存操作が反転後の選択にも自然に働くように)。
- **全選択の反転は選択解除と同じ**(選択なしになる)。選択も浮動片も無いときは無効(グレーアウト、他の選択依存項目と同じ)。
- 浮動片がある場合は**先に確定してから**(ツール切替と同じ commit-first 規則)、その足跡(確定位置のマスク)を反転対象にする。
- 選択の反転自体は履歴に積まない(選択の作成/解除が履歴対象外なのと同じ)。

## 38. 結合部分をコピー

- 編集グループに「**結合部分をコピー**」(**Ctrl+Shift+C**、PS 準拠)を追加する(§33 の編集グループ「コピー」の直後に追記)。
- 通常のコピー(Ctrl+C、アクティブレイヤーのみ)と違い、選択範囲の**可視レイヤー合成結果**(スポイトと同じ「見えているとおり」の画素、§13)をクリップボードへコピーする。
- 浮動片がある場合はその足跡を対象範囲とし、合成結果の上に浮動片を重ねた「画面表示と同じ」画素をコピーする。**ドキュメント・選択・浮動片・履歴の状態は一切変更しない**(非破壊。浮動片の確定もしない)。
- 選択も浮動片も無いときは無効。クリップボードへの書き込み失敗はトースト(§8)。「結合切り取り」は作らない(切り取りは常にアクティブレイヤー対象のまま)。

## 39. v8 キーマップ追加(§20 に追記)

| キー | 動作 |
|---|---|
| Ctrl+Shift+I | 選択範囲を反転 |
| Ctrl+Shift+C | 結合部分をコピー |

- どちらも修飾キーの多い側が先に消費される(Ctrl+Shift+I は Ctrl+I=階調の反転、Ctrl+Shift+C は Ctrl+C=コピーと衝突しない。Ctrl+Shift+Z と Ctrl+Z の既存規則と同じ)。
- キーマップは引き続き keymap.rs の単一テーブルが正。メニュー表記・ツールチップ・README のショートカット表もこの表に追随させる。

## 40. v8 の修正(外部レビュー起点、動作保証の明文化)

v8 で第三者レビュー(Codex)の指摘を受けて確定した動作保証。いずれも既存仕様の穴を塞ぐもので、新しい UI は増えない。

1. **画像書き出しの原子性**: PNG/JPEG/BMP の保存も `.dpaint`(§36)と同じ「同一ディレクトリの一時ファイル→単一 rename で置換」で行う。書き出しの途中失敗で既存ファイルが空・不完全に壊れることはない(失敗時は旧ファイル維持+トースト)。
2. **読み込みの寸法上限**: 「開く」・クリップボード貼り付けは 1 辺 **8192px**(§7 の新規ダイアログ・§16 の拡縮・§36 の `.dpaint` と同じ上限)を超える画像を明確なエラーメッセージで拒否する(確保だけで OOM 中断しない)。
3. **選択マスクの確保上限**: 矩形/楕円/なげなわ選択のマスク確保はドキュメントとの交差領域に限る(キャンバス外への極端なドラッグで文書サイズと無関係な巨大確保をしない)。楕円の形状はクリップ前の外接矩形から計算する(§22 の図形との見た目一致は不変)。
4. **浮動片コピーのマスク適用**: 非矩形選択の浮動片を Ctrl+C/Ctrl+X したとき、マスク外の画素は透明としてコピーされる(§21 のマスク形状維持)。
5. **Esc キャンセルと未保存表示**: 浮動片の Esc キャンセル、および 1px も動かさなかった確定(履歴に積まれない no-op)は、`modified`(未保存表示 `*`)も浮動化前の値へ戻す(§18 の「完全復元」)。浮動片の保持中にレイヤー名の確定など履歴外の実変更があった場合は戻さない(未保存ガード優先)。
6. **保存パスの一意性**: 「名前を付けて保存」で他のタブが開いているパスへ保存した場合、そのタブはパスの紐付けを失い「無題」(未保存)へ戻る(内容は失わない)。同じパスを複数タブが保持して Ctrl+S で黙って上書きし合う状態を作らない(§30 の「同じファイルは 1 タブ」の趣旨)。
7. **undo→redo とレイヤーメタデータ**: レイヤーの追加/複製を undo→redo しても、その後に変更した名前(追加)・名前/表示/不透明度(複製)は失われない(undo 時点の値で redo する。§13 の「表示・不透明度は履歴に積まない」と両立)。既知の残課題: 追加レイヤーの表示/不透明度と、結合(§13)後のメタデータ変更は redo で既定値に戻る(`.dpaint` v1 の符号化互換を優先して見送り)。
8. **設定ファイルの読込上限**: `settings.txt` が 1MB を超える場合は破損とみなし黙って既定値で起動する(§26 の防御の強化)。
9. **CI のサイズ検査**: exe 15MB 上限(§0)を CI とリリースワークフローで検査する(§29 の強化)。

# v9 拡張仕様(保存状態の正確化・ナッジ・選択の変形・ファイル貼り付け・テーマ)

v1〜v8 の全要件は v9 でも維持する。第 2 ラウンドの外部レビュー(Codex)と自己レビューで確定した「最小限だが完成したペイントソフト」への仕上げ。

## 41. 矢印キーのナッジ(§20 に追記)

- **矢印キー**: 浮動片があればそれを 1px 移動。無ければ選択枠だけを 1px 移動(画素は動かさない — PS の選択ツール準拠)。**Shift+矢印**は 10px。キャンバス端では**移動量をクランプ**する(選択が欠けたり消えたりしない — 端で止まる。v11 R3 修正)。
- どちらも無ければ何もしない。移動自体は履歴に積まない(ドラッグ移動と同じ「確定時に 1 undo 単位」)。テキスト入力中は無効(既存の単一キーガードと同じ)。

## 42. 選択範囲・浮動片の反転/回転

- 画像メニューの 左右反転 / 上下反転 / 右に90°回転 / 左に90°回転 は、**浮動片(または選択 — 先に §18 の自由変形と同じ経路で浮動化)がある場合はその対象だけ**に適用する(MS ペイント準拠)。無ければ従来どおり全レイヤーへ適用(§7)。
- 回転は浮動片の見た目の中心を維持して幅高を入れ替える(回転後の位置は**整数座標へ丸める** — 縦横の偶奇が異なる場合の中心誤差は最大 0.5px。本体・枠・確定位置の一致を優先する。v11 R3 修正)。変換は履歴に積まず、確定時にまとめて 1 undo 単位(Esc で丸ごとキャンセル可、§18)。
- 変換後の画素が以後のハンドル拡縮の再サンプリング元になる(累積劣化させない規則は §16 のまま)。

## 43. ファイルから貼り付け

- 編集グループに「**ファイルから貼り付け…**」を追加(「貼り付け」の直後。MS ペイントの「貼り付け元」相当)。ショートカットは割り当てない。
- 画像ファイル(PNG/JPEG/BMP/GIF/WebP、寸法上限は §40-2 と同じ 8192)を選び、クリップボード貼り付け(§6)と同じ規則で処理する: 白紙ならドキュメント置き換え、それ以外はビュー中央へ浮動片として配置。`.dpaint` は対象外(「開く」で別タブに開く)。

## 44. ビジュアルテーマ

- egui 既定のダークテーマに代えて、**青みがかったダークグレー 3 階調+単一アクセント色(落ち着いた青)**の固定テーマを適用する(`ui/theme.rs`、起動時 1 回)。OS のライト/ダーク設定に追随しない(UI は常にダーク — 描画色の見えが環境で変わらないことを優先)。
- 画像アセット・フォント・依存 crate は追加しない。起動時間・アイドル CPU への影響はない(§0 不変)。
- キャンバス作業領域(§3 の「暗灰色」)もテーマ階調に合わせた暗色とする(仕様の範囲内の色調整)。

## 45. v9 の修正(第 2 ラウンドレビュー起点)

1. **保存カーソルと未保存表示の同期**(§40-① の残課題解消): 保存時点の履歴位置を記録し、undo/redo/履歴ジャンプでその位置へ戻り、かつ履歴外のメタ変更(レイヤー名・表示・不透明度)が無ければ未保存表示(`*`)を消す。保存位置より手前で新しい操作をしたら以後は常に未保存扱い。新規文書は初期状態(白紙)が基準(全部 undo すれば未保存表示が消える)。
2. **表示切替・不透明度・リネームの commit-first**(§40 既知課題②の解消): 履歴に積まないレイヤー操作(§13)も、他のレイヤー操作と同じく進行中のストローク・浮動片を先に確定してから適用する(§13 最終項の全面適用)。
3. **画像形式への保存は「書き出し」**(§36 の意味論の強制): レイヤーが複数ある、または `.dpaint` に紐付いた文書を PNG/JPEG/BMP へ保存しても、タブのパス・未保存状態は変わらない(トーストで「プロジェクトとしては未保存」と明示。未保存ガードから画像形式を選んだ場合、閉じる処理は続行しない)。単一レイヤーかつ `.dpaint` 非紐付きの文書だけは従来どおり画像ファイルを「開いて編集」する MS ペイント型の意味を保つ。
4. **浮動片プレビューのマスク適用**: 非矩形浮動片の画面表示を確定・コピーと同じ「マスク外は透明」で描く(拡縮の再サンプリングでマスク外に残る画素が見えない)。
5. **結合コピーの足跡はクランプしない**: 浮動片がキャンバス外にはみ出していても、通常コピーと同じく足跡全体を対象にする(キャンバス外は透明+浮動片)。
6. **読込の競合窓の解消**: 「開く」の寸法検査とデコード、`settings.txt` の上限検査と読込を、同一ファイルハンドルで行う。
7. **保存メモリの削減**: `.dpaint`・画像書き出しとも一時ファイルへのストリーム書き出しにし、完成ファイル全体のメモリ組み立てを廃止。浮動片の再サンプリング元(§16)は最初の拡縮まで複製しない。`.dpaint` の読込検証に「Patch 領域のタイル格子整合・重複禁止」を追加(§36 の防御強化)。

# v10 拡張仕様(透明な選択・`.dpaint` v2)

v1〜v9 の全要件は v10 でも維持する。

## 46. 透明な選択

- 選択系ツール(矩形/楕円選択・なげなわ・自動選択)と移動ツールのオプションバーに「**透明な選択**」チェックボックスを追加する(MS ペイント準拠。既定 OFF・永続化しない — なげなわのモードと同じ扱い)。
- ON のとき、**セカンダリ色と RGB が完全一致する画素**(アルファは比較しない)を次の操作で選択から除外する:
  - **浮動化**(選択ドラッグ・移動ツール・自由変形・ハンドル掴み): 除外された画素は持ち上げられず、切り出し元でも透明化されない(その場に残る)。キャンセル・確定は既存のマスク機構でそのまま整合する。
  - **貼り付け**(Ctrl+V / ファイルから貼り付け): 貼り付けた浮動片のマスクから除外し、**除外画素は画素自体も透明化**する(ハンドル拡縮の再サンプリングでキー色が選択内へにじみ戻らないように。v11 R3 修正)。テキスト確定の浮動片には適用しない(文字色がセカンダリの場合に文字が消えるため)。白紙置換貼り付け(§6)にも適用しない(文書ごと差し替える操作のため)。
- 許容値は 0(完全一致)固定。判定はアクティブレイヤーの画素(浮動化)/貼り付け画素そのもの。

## 47. `.dpaint` v2(レイヤーメタの完全復元 — §40-7 の残課題解消)

- ヘッダの version を **2** に上げる。読み込みは **v1(v0.7〜v0.9)と v2 の両方**を受け付け、書き込みは常に v2。
- 符号化の変更(REVS chunk 内のみ):

## 50. レイヤー UX 刷新

### 50.1 レイヤーパネル

- 行 = **[目アイコン] [サムネイル] [名前]**。アクティブ行ハイライト・クリックでアクティブ化・ダブルクリックでリネームは従来どおり。
- **目アイコン**: チェックボックスを廃止し、`ui/icons.rs` のベクター描画(表示=目、非表示=斜線付きの目)。挙動は従来と同一(履歴に積まない・commit-first — §13)。
- **サムネイル**: 最大 40×30・縦横比維持・市松下地。内容は**そのレイヤーの画素のみ**(visible/opacity/blend を反映しない — よって表示/不透明度/ブレンド変更での再生成は不要)。
  - 再生成は**変更境界のみ**(毎フレーム禁止 — アイドル CPU 0%): 成功したストローク確定 / ReplaceAll 系 / レイヤー構造変更 / undo・redo・履歴ジャンプ / 新規・開く・プロジェクト読込・ページ置換 / Delete・切り取り・貼り付け確定・テキスト確定・即時色調補正・モザイク・修復の適用。実装は「Document の成功した変更で**単調増加する世代カウンタ**」を正とし(undo で巻き戻らない)、UI 側イベントの個別列挙に依存しない。
  - キャッシュはタブごと。レイヤー行あたりテクスチャ 1 枚を**置換**(無限に増やさない)。可視行のみ生成・1 フレームの生成枚数に上限・初回はプレースホルダ。構造変更・スナップショット復元時は全消去。

- **右パネルの構成変更**: 「色 / レイヤー / 履歴(/ ページ §54)」を**折りたたみセクション**にする(レイヤーとページは既定で展開)。レイヤー一覧の高さは固定 180px をやめ、展開セクションで残り高さを優先配分する(パネル全体とリストの二重スクロールを作らない)。
- 不透明度スライダー・ブレンドモード(50.2)・アルファロック(50.3)は一覧の直上に置く。

### 50.2 ブレンドモード(§2 の非目標を解除)

- 各レイヤーに **blend: 通常 / 乗算 / スクリーン / オーバーレイ / 加算**(既定: 通常)。UI は ComboBox。**履歴に積まない**(表示/不透明度と同じ §13 規則)。変更は commit-first + 全面 dirty + `modified`/`meta_dirty` 更新(§45-1 の未保存判定に参加)。
- 合成式(正規化 straight-alpha。W3C compositing-1 の「ブレンド→合成」2 段階):

```
αs = src_a × layer_opacity
Cr = (1 − αb)·Cs + αb·B(Cb, Cs)        // ブレンド後の source 色
αo = αs + αb·(1 − αs)
co = αs·Cr + αb·(1 − αs)·Cb            // premultiplied 出力
Co = αo > 0 ? co / αo : 0              // straight RGB(αo=0 は透明黒)
```

  B: 乗算 `Cb·Cs` / スクリーン `1−(1−Cb)(1−Cs)` / オーバーレイ `hard-light(Cs, Cb)`(Cb ≤ 0.5 → `2·Cb·Cs`、他は `1 − 2(1−Cb)(1−Cs)`)/ 加算 `min(1, Cb + Cs)`(W3C 外の定番としてクランプ和)。演算は encoded sRGB 上で行い、丸め規則は実装で固定してテストで検証する。**通常モードは従来の source-over と結果完全一致**(回帰テスト必須)。
- 適用箇所は `composite_layers`(再合成・結合・統合・書き出しの共通経路)。ブレンド関数の解決はレイヤーごとに 1 回(画素ごとの分岐禁止)。全レイヤー通常の文書は従来コードパス(fast path)で性能不変。非通常使用時も 4000×4000 全面再合成の劣化 2 倍以内。
- **「下と結合」の制限**: 結合対象 2 枚のどちらかが通常以外なら無効(グレーアウト+実行時トースト)。非通常ブレンドは下の**累積 backdrop** に依存するため 2 枚だけの焼き込みでは見た目を保存できない。「画像の統合」は常に可(見た目=合成結果そのものを 1 枚にする)。
- AddLayer/MergeDown の undo 時メタ刷新(§40-7/§47)を blend にも拡張する。

### 50.3 アルファロック(透明部分の保護)

- 各レイヤーに **alpha_lock: bool**(既定 OFF)。パネルの一覧直上にトグル(市松+錠のアイコン)。**履歴に積まない**・commit-first・`modified`/`meta_dirty` 更新。表示には影響しないため dirty は不要。
- ON のとき、アクティブレイヤーへの描画系操作(ブラシ/鉛筆/消しゴム/図形/塗りつぶし/グラデーション/色調補正/モザイク §51/内蔵修復 §53/プラグイン書き戻し §55〜§56)は:
  - `dst_a == 0` の画素: **RGBA とも完全不変**(合成自体をスキップ — 「書いてから α を戻す」は RGB が汚れるため禁止)。
  - `dst_a > 0` の画素: α は元値のまま固定し、**RGB のみ**カバレッジ補間。
  - 消しゴムは α を減らせないため**全画素 no-op**(空の undo 単位を積まない。使用時に「透明保護中は消しゴムは効きません」トースト)。
- 塗りつぶしの直接書き込み経路も alpha-aware に変更する(`set_pixel` を通らない現行の直接代入を含む)。
- **浮動片の確定合成・貼り付け・テキスト確定には適用しない**(移動・貼り付けの意味論を保つ)。

### 50.4 `.dpaint` v3

## 51. モザイク・選択ブラシ

### 51.1 モザイク

- 画像メニューの色調補正グループに「**モザイク…**」。対象: アクティブレイヤー、選択があれば選択内、なければ全面(§24 と同じ規則)。適用は 1 undo 単位。
- **ライブプレビュー付きモーダル**(§24 と同じ状態機械 — 開始時スナップショットから毎回再計算、OK で Patch 化、キャンセルで復元)。
- 「**自動**」チェック(既定 ON): ブロックサイズ = `長辺 ≥ 400 ? max(4, 長辺 / 100) : 4`(mosaic_editor の審査基準準拠ロジック)。自動時は実値をダイアログに表示。手動スライダー 2〜100。
- アルゴリズムは **Rust 独自の「原点 (0,0) 固定格子のブロック平均」**(mosaic_editor は cv2 の縮小/拡大補間であり厳密には異なる — 「同一挙動」は謳わない)。格子は画像全体に固定(マスク形状非依存 — 隣接して 2 回かけても格子がズレない)。ブロック平均には選択マスク外の画素も含み、**置換は選択内の画素のみ**(mosaic_editor の「全体をモザイク化して選択内だけ採用」と同じ意味論)。端の欠けブロックは実在画素のみで平均。
- 平均は **α 加重**(RGB は α 重み付き平均、α は単純平均。全透明ブロックは透明黒)。アルファロック時は §50.3(α 保存・`dst_a==0` スキップ)。
- テスト: 格子整列 / 端ブロック / α 加重 / マスククリップ / 自動値の境界(399・400・499・500)。

### 51.2 選択ブラシ(クイックマスク簡易版)

- 新ツール「**選択ブラシ**」(キー **Shift+W** — 自動選択 W と巡回。keymap.rs 単一テーブル+ 1:1 テスト追随。ツールバーにアイコン追加)。
- ドラッグで選択マスクへ**追加**、**Alt ドラッグで消去**(オプションバーに 追加/消去 モード表示)。円ブラシ・サイズはブラシサイズ共有・2 値(硬さ概念なし)。
- 既存選択が無ければ空のマスクから開始。ストローク終了(Up)ごとに選択境界を再計算・マスクが空になったら選択解除。以後の選択の使われ方(浮動化・メニュー・描画クリップ)は既存のマスク選択と同一。
- 背景: mosaic_editor の「ペンでマスクを塗って→モザイク」ワークフローの移植。既存選択ツールは常に「置き換え」(§22)で蓄積編集ができないため。§22 の「置き換え」原則はこのツール以外では不変。

## 52. 縦書きテキスト

- テキストツールのオプションに「**縦書き**」チェック(既定 OFF)+「**文字間**」0〜50px(既定 0)+「**行間**」0〜100px(既定 0)。文字間・行間は**横書きにも適用**(横: 字送り・行送りへの加算)。3 項目とも §26 の永続化対象に追加。
- 縦書きレイアウト(manga_tool 準拠の**簡略移植** — ピクセル完全一致は謳わない):
  - `\n` で**列**に分割し、**最初の列を最も右**、以降を左へ(Enter = 新しい列が左に増える)。列間 = 行間設定。
  - 縦の字送りは**固定送り**: フォント height(ascent − descent + line_gap)+ 文字間(グリフごとの advance ではない — manga_tool の `fm.height() + spacing` 準拠)。空列は全角 1 文字ぶんの幅のセルを占める。
  - **回転文字**(manga_tool の集合そのまま・全角のみ): `ー―─━…‥〜～「」『』（）【】〔〕〈〉《》｛｝` はセル中心で 90° 回転(カバレッジの transpose + flip)。
  - **句読点** `。、` はセルの右上寄せ(右へ半セル・上へ半セル)。その他の文字はセル内で水平センタリング。
- 編集 UI: インライン TextEdit は横書き入力のまま。**縦書きモード中はテキスト・設定が変わったフレームだけ**確定と同じラスタライザでプレビューを生成し、クリック位置に重ね描きする(タイピングの無いフレームでは再計算しない — アイドル CPU 0%)。確定(Ctrl+Enter/外クリック)・Esc 破棄は従来どおり。
- 寸法・確保は checked 演算とし、失敗はエラーを返す(既存の横書き `rasterize_text` の `width*height*4` も同時に checked 化)。純関数+テスト(列順が右→左 / 回転文字の ink 幅高入替 / 句読点位置 / 文字間・行間の寸法反映 / 空列 / 巨大入力で Err)。

### 52.2 袋文字(縁取り)

漫画のセリフ・効果音で必須の「白フチ文字」。**横書き・縦書きの両方**で同じように使える(ラスタライズ経路が共通なので、レイアウトの種類に関係なく同じ設定が効く)。

- オプションバーに「**袋文字**」チェック(既定 OFF)+「**縁の太さ**」1〜20px(既定 3)。
- **色の割り当てはアプリ共通の流儀に従う**: 文字の塗り = **プライマリ色**(従来どおり)、縁 = **セカンダリ色**。新しい色状態は増やさない(右パネルの 2 スウォッチと `X` キーの入替がそのまま使えるのが最も分かりやすい)。オプションバーには「縁: セカンダリ色」と明示し、現在のセカンダリ色の小さなスウォッチを併記する。
- 縁は**文字の外側だけ**に描く: 文字の被覆を太さぶん膨張させた領域から、文字自身の被覆を差し引いた部分に縁色を置く。塗りと縁は重ならないので、**半透明のプライマリ色でも縁が透けて濁らない**(予測しやすさを優先)。
- 縁の角は**丸く**なめらかに繋ぐ(距離場に基づく膨張。角ばった正方形の膨張にしない)。境界はアンチエイリアスする。
- 結果バッファは縁の太さぶん上下左右へ広げる(縁が切れない)。ただし**クリック位置に対する文字の見た目の位置は袋文字 ON/OFF で変わらない**(広げた分だけ配置位置をずらして相殺する)。
- プレビュー(§52 の縦書きプレビュー)にも同じ設定で反映する。1 辺 8192px の上限は**膨張後の寸法**で判定する。
- 永続化(§26 に追加): 袋文字の ON/OFF・縁の太さ。

## 53. 選択範囲を修復(内蔵・非 AI)

- 編集メニューに「**選択範囲を修復**」(選択があるときのみ有効。浮動片は commit-first)。アクティブレイヤー対象・1 undo 単位。
- アルゴリズム: **Telea 2004(FMM)の純 Rust 再実装**(IOpaint が cv2 経由で提供する INPAINT_TELEA 相当。依存追加なし・`std::collections::BinaryHeap`)。半径 5px 固定。品質の位置づけ: 小さな不要物・文字・傷向け。**AI 品質は目標としない**(それは §55 のプラグイン)。
- 実行は**ワーカースレッド**(`thread::Builder::spawn` — 生成失敗は Result → トースト)。選択 bbox + 半径マージンの画素スナップショットを渡し、完了時に §55.1 の世代ガードを通ったときだけ 1 undo 適用 + `request_repaint` 1 回。実行中はステータスバー表示+キャンセル(結果破棄)・同種ジョブの多重発行禁止。
- 上限: 未知(選択)画素数 **MAX_INPAINT_PIXELS = 4,000,000**。超過はトーストで拒否(縮小を促す)。距離場・ヒープ・出力バッファは `try_reserve` + checked 演算。ヒープ順序は `f32::total_cmp` + 添字タイブレーク(`partial_cmp().unwrap()` 禁止)。
- 全面選択(既知画素が 1 つもない)はエラートースト。α の扱い: 通常時は RGBA とも修復、アルファロック時は §50.3(α 保存・`dst_a==0` スキップ)。
- テスト: 単色領域の完全復元 / 線形勾配の誤差上限 / 全面マスク Err / 1px マスク / 画像端接触 / 上限超過 Err / 同一入力の決定性。

## 54. ページ管理パネル

- ファイルメニューに「**フォルダをページとして開く…**」+**フォルダの D&D** でも同じ。フォルダ直下の対応ファイル(PNG/JPEG/BMP/GIF/WebP/.dpaint)を**ファイル名の自然順**(数値部分は数値比較)で**ページ集**としてアクティブタブに紐付ける。対応ファイル 0 件はトースト。
- 右パネルに「**ページ**」セクション(§50.1 の折りたたみ構成に追加)。行 = ページ番号 + サムネイル + ファイル名。現在ページをハイライト。クリックでそのページへ移動。
- **ページ移動 = アクティブタブの内容の置き換え**(タブは増えない)。**トランザクショナル**に行う: ①未保存確認(下記)→ ②移動先のロード**成功**→ ③置換。失敗・キャンセル時は現在ページに留まる。移動先パスが他タブで開かれている場合は置換せず**そのタブへ切り替え**(§30「同じファイルは 1 タブ」準拠)+トースト。
- 未保存確認は既存の未保存ガード(保存/破棄/キャンセル)を `SwitchPage` 用の pending action として通す。**「ページ切替時に自動保存」チェック(既定 OFF)**: ON のとき、**上書き保存が完全な忠実度を持つ場合のみ**(単一レイヤー・画像パスの MS ペイント型文書 §45-3、または `.dpaint` 紐付き文書)確認なしで保存→移動。多層×画像パス(保存が「書き出し」になり未保存が解けない)や GIF/WebP パス(書き込み非対応形式)は自動保存できず、通常の確認ダイアログに落とす。
- ページ切替時、履歴・選択・浮動片・ズーム/パン・リネーム状態は「開く」と同様に全リセット。ページ集の紐付け・自動保存設定は維持。タブごとに独立。セッション永続化はしない。
- キー: **PageUp / PageDown** で前/次ページ(keymap.rs 追加)。
- サムネイル: **可視行のみ**、有界のワーカーキューでデコード→縮小し、結果到着時に 1 回だけ repaint(毎フレーム再試行しない。失敗はプレースホルダをキャッシュ)。**`.dpaint` は汎用アイコン**(サムネイル目的でフルロードしない)。フォルダ列挙・デコード失敗は Result +トースト。非 Unicode ファイル名は PathBuf/OsStr のまま扱う。
- ページの並べ替え・追加・削除・リネームは対象外(閲覧と移動に限定 — ファイル管理はエクスプローラの仕事)。

## 55. 外部プラグイン連携基盤 + AI 修復(IOpaint)

### 55.1 原則(§2 の非目標更新に対応)

- プラグイン = **別リポジトリ・別インストールの外部プロセス**。本体リリースに一切同梱しない。**起動時の探索・自動起動・接続・ヘルスチェックをしない**(メニュー実行時のみ接続)。プラグイン未導入でも全内蔵機能が完全動作する。
- 接続先は **127.0.0.1 固定**(ホスト設定は存在しない)。設定はポート番号のみ(§26 に `plugin_iopaint_port` 既定 8423 / `plugin_diffusion_port` 既定 8424 を追加。設定ダイアログ §34 に数値欄)。**リダイレクトは拒否**。応答サイズ・画像寸法に数値上限。
- 通信は std のみ: `TcpStream` 上の最小 HTTP/1.1 クライアント(Content-Length/chunked 両対応・接続/読取タイムアウト)+ **手書き base64** + **固定スキーマの手書き JSON**(§26 の settings パーサと同じ流儀。純関数はテスト必須)。リクエストボディは全体をメモリに組み立てず**ソケットへストリーム書き込み**(base64 の二重バッファ化禁止)。
- **送信画素は選択 bbox + コンテキストマージン 128px のみ**(レイヤー全面送信は禁止 — OOM 防止)。応答から採用するのは**マスク内画素のみ**。修復・置換の書き戻しは RGB のみ採用し α は元値保持を既定とする(アルファロックは §50.3 に従う)。
- **非同期実行**: `thread::Builder::spawn`(失敗 Result → トースト)。発行時に(**タブ安定 ID**・文書世代・選択世代・JobId)を捕捉し、完了時に UI スレッドで**全一致+進行中ストローク無し**のときだけ 1 undo 適用。不一致は破棄+トースト。同種ジョブの多重発行禁止(single-flight。キャンセル後も旧ワーカー終了までは占有)。実行中はステータスバーに表示+キャンセル(結果破棄)。完了時の `request_repaint` は 1 回(ポーリング・スピナーアニメーション禁止)。**タブに安定 ID(作成順の単調増分 u64)を導入する**(添字は削除で詰まるため識別子にしない)。
- 実行時にまず `GET /api/v1/health` で**プラグイン種別・API バージョン・モデル**を確認してから画像を送る。不一致・未起動は案内トースト(「darask-plugin.bat を実行してください」)。

### 55.2 AI 修復(IOpaint プラグイン。リポジトリ: daraskme/darask-paint-iopaint — 公開済み)

- 役割 = **消す**: 編集メニュー「**AI 修復(IOpaint)…**」— 選択必須。選択領域を LaMa で修復し、マスク内だけ書き戻し(1 undo)。§55.1 の基盤に全面的に載る。
- API: `POST /api/v1/inpaint`(image/mask は base64 の JSON。**応答は生画像バイト**であり base64 JSON ではない)。
- プラグイン側の必須作業(fork 側): **`--darask-plugin-mode`** を追加 — 専用の health/inpaint ルートだけを公開し、**Web UI・WebSocket・CORS・モデル切替 API を無効化**、モデルを LaMa に固定し、inpaint を直列化する。`darask-plugin.bat` はこのモードで起動する。エンジンは fork のリリース wheel を**版固定**で使用する。

## 58. ドッキングパネル(右パネルの自由配置)

右パネル固定だった「色 / レイヤー / 履歴 / ページ」の各セクションを**パネル**として一般化し、ユーザーが自由に配置できるようにする(ユーザー要望)。依存 crate は追加しない(egui 標準の Window / drag & drop のみ。egui_dock 等は使わない)。

- 各パネルは 3 状態: **右ドック / 左ドック / フローティング**。既定は全パネル右ドック(順: 色→レイヤー→履歴→ページ)。
- **パネルヘッダのドラッグ**で移動:
  - ドック内でドラッグ → 並び替え(挿入位置インジケータ。§50.1 のレイヤー行 DnD と同じ流儀)。
  - ドック領域の外へドラッグ → **フローティング化**(egui::Window。自由配置・リサイズ可・タイトルバー付き)。
  - フローティングのタイトルバーを左右ドック領域へドラッグ → 再ドック(挿入位置に入る)。
- ヘッダの「▾」メニュー(右クリックでも可)からも「右にドック / 左にドック / フローティング化」を選べる(ドラッグ操作の代替)。
- **左ドック**はツールバーの右隣・幅約 210px(パネルが 1 つ以上あるときのみ出現)。**右ドックが空なら右パネル自体を出さない**(キャンバス最大化)。
- 折りたたみ(§50.1)は全状態で従来どおり。
- **レイアウトの永続化**(§26 追加): 各パネルの配置(right/left/float)・ドック内順序・折りたたみ状態・フローティングの位置と寸法。破損時は既定配置(§26 の「黙って既定値」)。フローティング座標が画面外になった場合は表示範囲内へクランプして復元。
- 表示メニューに「**パネル配置をリセット**」を追加(既定配置へ戻す。設定にも反映)。
- 非目標: タブグループ化・分割ネスト等の完全なドッキングフレームワーク(シンプルさ優先)。アニメーションなし(アイドル CPU 0%)。

## 59. メニューバーの整理(§33 の「全項目を常時表示」を上書き)

v6 §33 で全メニュー項目を常時表示のアイコンタイルにしたが、v12 で項目が 49 個まで増え、標準ウィンドウ幅(1280px)で **3 行**を占めるようになった(キャンバスの縦を圧迫する)。Phase 5・6 でさらに増えるため、**よく使うものは常時表示のまま、めったに使わないものと同じ家族の操作はグループにまとめる**(ユーザー要望)。

- **常時表示タイル(9)**: 描画中に頻繁に押し、かつ他に手軽な代替がないもの。
  新規 / 開く / 上書き保存 / 元に戻す / やり直し / 切り取り / コピー / 貼り付け / 自由変形
- **グループタイル(9)**: クリックで小さなポップアップを開き、その中に項目を縦に並べる(§33 が「最近使ったファイル」に許した形式の一般化)。
  | グループ | 中身 | まとめる理由 |
  |---|---|---|
  | **ファイル…** | 名前を付けて保存 / ファイルから貼り付け / 最近使ったファイル / タブを閉じる / 終了 | ファイル起点の操作。使用頻度が低いか、ショートカットで足りる |
  | **選択…** | すべて選択 / 選択解除 / 選択範囲を反転 / 削除 / 結合部分をコピー / 選択範囲を新規タブに複製 / 選択範囲を切り取って新規タブへ | すべて選択範囲に対する操作 |
  | **サイズ…** | 画像サイズ変更 / キャンバスサイズ変更 / 選択範囲でトリミング | 文書の寸法を変える操作 |
  | **変形…** | 左右反転 / 上下反転 / 右に 90°回転 / 左に 90°回転 | 同じ家族。単独で常時表示する必要がない |
  | **色調補正…** | 明るさ・コントラスト / 色相・彩度・明度 / 階調の反転 / グレースケール化 / モザイク | 画素の色を変える操作 |
  | **AI・修復…** | 選択範囲を修復 / AI 修復(IOpaint) / AI 生成(Diffusion) / AI 置換(Diffusion) | 「選択範囲を作って任せる」操作。§55・§56 の追加分もここへ入る |
  | **レイヤー…** | 新規レイヤー / 複製 / 削除 / 上へ / 下へ / 下と結合 / 画像の統合 | **右パネルに同じボタンがある**ため常時表示の価値が低い |
  | **表示…** | 拡大 / 縮小 / 100% / ウィンドウに合わせる / ピクセルグリッド表示 | ホイールとショートカットで日常的に足りる |
  | **その他…** | 設定 / パネル配置をリセット / バージョン情報 | めったに使わない |
- 並び(区切り線でカテゴリを示す): `新規 開く 上書き保存 ファイル… | 元に戻す やり直し 切り取り コピー 貼り付け 自由変形 選択… | サイズ… 変形… 色調補正… AI・修復… | レイヤー… | 表示… その他…`
- **標準ウィンドウ幅(1280px)で 1 行に収まること**を要件とする(最小幅 640px でも 2 行以内)。
- ポップアップの行は **アイコン + 完全な日本語名 + ショートカット表記**(右寄せ)。無効な項目はグレーアウト(常時表示タイルと同じ判定)。Esc・外側クリック・項目実行で閉じる。**ショートカットキーの割り当てと動作は一切変更しない**(メニューを畳んでも従来どおりキーで直接実行できる)。

- 「最近使ったファイル」は ファイル… ポップアップ内の一覧セクションとして表示する(§26 の挙動は不変)。
- 各項目の実際の動作・確認ダイアログ・履歴の扱いは v1〜v12 の既存仕様から**一切変更しない**(変わるのは配置だけ)。
